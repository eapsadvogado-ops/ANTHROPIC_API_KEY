# Skills — Pesquisa Doutoral em Direito e Sociologia do Direito

Pacote de *skills* do Claude Code voltado à pesquisa acadêmica de nível doutorado em Direito, com ênfase em Raça e Racismo, Sociologia do Direito, Sociologia Política, Teoria dos Sistemas e Teoria Constitucional.

Cada skill é acionada automaticamente pelo Claude Code quando a tarefa corresponde à sua descrição, ou pode ser invocada diretamente.

## Skills incluídas

| Skill | Uso |
|---|---|
| `metodologia-pesquisa-juridica` | Desenho metodológico: problema, hipótese, objetivos, escolha de método (dogmático, zetético, empírico-jurídico, comparado). |
| `revisao-bibliografica-juridica` | Mapeamento do estado da arte e síntese crítica de correntes teóricas. |
| `redacao-academica-juridica` | Registro, precisão terminológica e estrutura argumentativa do texto acadêmico. |
| `citacoes-abnt` | Formatação de citações e referências conforme ABNT (NBR 6023, 10520, 14724). |
| `analise-jurisprudencial` | Análise de acórdãos e construção de corpus jurisprudencial como dado de pesquisa. |
| `teoria-dos-sistemas-aplicada` | Ferramental conceitual de Luhmann e Marcelo Neves (diferenciação funcional, código/programa, constitucionalização simbólica). |
| `teoria-racial-critica` | Precisão conceitual entre racismo estrutural, institucional e sistêmico; autores de referência. |
| `fichamento-fontes` | Técnica de fichamento analítico de fontes para reuso em revisão bibliográfica. |
| `estrutura-tese-doutorado` | Arquitetura geral da tese: introdução, capítulos, conclusão, coerência argumentativa. |

## Uso

As skills estão em `.claude/skills/`. Basta pedir a tarefa correspondente (ex.: "revise a metodologia deste capítulo", "fiche este artigo", "formate estas referências em ABNT") que o Claude Code aciona a skill pertinente automaticamente.
